# Паритет web ↔ RN по страницам

Живая таблица: что есть на вебе, что есть в мобильном клиенте и где они
расходятся. Правится по мере проходов, а не переписывается с нуля.

## Как читать

- **ОК** - экран делает то же самое; различия только платформенные (жесты,
  пиксели, PWA).
- **copy** - не хватает подписи/заголовка, действие есть.
- **info** - на экране меньше данных (статистика, метаданные, состояния).
- **action** - на телефоне нельзя сделать то, что можно на вебе.
- **web-only** - так задумано: SEO, PWA, legal, калькуляторы, Turnstile.

## Закрыто в проходе 2026-11-21

Первый срез (программы и подбор) описан в `rn-visual-backlog.md`. Второй срез,
по результатам построчного аудита всех пар:

- **Главная.** Карточка «Создать тренировку» без планов (`HomeCreateCard`),
  приветствие скрыто у гостя, чек-лист онбординга гаснет после первого плана,
  «кг» больше не захардкожен, карточки прогресса идут за общим периодом
  (`repdraft:progress-period`) вместо фиксированных 30 дней.
- **Тренировки.** Вход в историю с вкладки (`workouts.openHistory`).
- **История.** Очистка истории в шапке с подтверждением (как на вебе).
- **Рекорды.** Пустое состояние с описанием и переходом в каталог, отдельное
  состояние «фильтр ничего не нашёл» со сбросом, спиннер вместо ложного «пусто»,
  строки без данных о весе/повторах отфильтрованы (`hasLiftData`).
- **Каталог.** Счётчики зон в режиме «дома» считаются по инвентарю атлета.
- **Билдер.** Отдых суперсета читается у последнего участника группы, а не у
  ведущего (было 0 и всегда +15).
- **План.** Ненайденная тренировка: пустое состояние `live.noPlan` вместо
  технического `builder.loadFail`.
- **Live.** «Далее» больше не блокируется, пока не закрыты все подходы (веб
  разрешает); замена упражнения с уже отмеченными подходами спрашивает
  подтверждение; «Другой вариант» скрыт, когда домен откажет; удалённая или
  пустая тренировка показывает пустое состояние, а не молчаливый редирект.
- **Итоги.** Удалённая сессия: пустое состояние вместо вечного скелета; в списке
  только упражнения с хотя бы одним отмеченным подходом; тип подхода пишется
  только для нерабочих подходов.
- **История: сессия.** В режиме правки есть «Отмена» (перечитывает из хранилища),
  свайп-удаление только в правке (раньше менял экран без сохранения),
  ненайденная сессия: пустое состояние.
- **Цикл.** Пустой онбординг ведёт сразу в билдер, цель берётся из профиля
  атлета, а не из константы.
- **AI.** Строки плана открывают упражнение, есть очистка поля и подсказка
  `aiDraft.briefHint`.
- **Прогресс.** Выбранное окно (7/30/90/всё) переживает перезапуск и совпадает
  с главной.
- **Профиль.** «Мой тренер» снова доступен: строка в настройках открывает шит
  с приглашением и отключением тренера (состояние было, входа не было).

## Открытые пункты

Собраны построчным аудитом пар; порядок - по важности для пользователя.
Каждый пункт с файлом, чтобы не потерялся.

### Действия, которых нет на телефоне

- `/builder/equipment` как отдельный вход в билдере (`builder.pickByEquipment`).
  В RN правила подбора уже есть в пикере, нет самой кнопки.
- «Подстроить под сегодня» (`planTune.*`, `/api/ai/tune-plan`) на превью плана.
  Домен и API общие, в RN нет ни CTA, ни шита с диффом.
- Диктовка брифа в `/ai` (`aiDraft.dictate*`): голос на вебе, в RN только текст.
- Техника-клипы (UGC: загрузка, галерея, жалобы) на странице упражнения.
- Смена типа подхода выбором из четырёх (в RN тап по номеру циклически меняет).
- История упражнения внутри live (`LiveExerciseHistorySheet`).
- Отмена удаления упражнения в билдере и сессии в истории (веб: undo-тост).
- Экран «проверьте почту» после magic link / сброса (в RN только Alert).
- Подтверждение пароля и живые подсказки политики при регистрации.

### Данные и состояния

- Главная: блок «Тренер» (`home.coachSection`) с подключёнными тренерами.
- История: свой диапазон дат, счётчики найденного, состояния облака
  (`workouts.cloud` / `workouts.local`), сортировка «следующий план сверху».
- Рекорды: фильтры по оборудованию и цели (в RN только часть тела), закладка.
- Каталог: полноценный список «все упражнения» и состояние ошибки индекса.
- План: строки суперсетов и «или» с раундами и лестницей (в RN одна строка).
- Live: контекст суперсета, метаданные чипов навигации, состояние
  «хранилище заполнено», выбор типа подхода.
- Итоги: панель помощи, гостевое «сохранить на сервере», заголовок и сворачивание
  списка упражнений, скрытие карточки объёма при нуле.
- История: сессия: правка клонирует только отмеченные подходы и ограничена
  `SETS.max`; «В план» на вебе грузит черновик билдера, в RN создаёт новый план.
- Упражнение: связанные статьи, подробная история (дельты, заметки, типы
  подходов), редактирование рекорда, ссылки-фасеты, состояние «не найдено».
- AI: проверка доступности провайдера до ввода, сохранение черновика при уходе
  с экрана.
- Прогресс: панель помощи (`progress.help*`).
- Настройки: удаление аккаунта с вводом слова-подтверждения, реальный
  `/settings/data` (сейчас редирект), управление Pro (веб-чекаут), карточка
  назначенного плана в профиле.
- Клиенты: демо-режим для превью (dev-only), fallback «напомнить» через буфер.
- Цикл: тосты создания/сброса/старта.
