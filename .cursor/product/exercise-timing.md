# Упражнения по времени (секунды / минуты)

Планка, вис, стенка — это время, а не повторы. Беговая дорожка, велотренажёр,
эллипс — тоже время, только в минутах. Реп-поле (`reps`) в таких упражнениях
хранит длительность, а не количество повторов — отдельного поля нет намеренно:
так не пришлось трогать 700+ мест, где читается `reps`.

## Данные

```ts
type ExerciseMeasure = 'reps' | 'seconds' | 'minutes';
```

- `WorkoutExercise.measure?: ExerciseMeasure` — в плане (билдер);
- `SessionExercise.measure?: ExerciseMeasure` — копируется в сессию при
  `startSessionFromPlan` / `replaceSessionPlan` / `syncSessionPrescriptionFromPlan`
  (`src/lib/domain/sessionLifecycle.ts`), поэтому live знает про время и после
  подмены плана на ходу;
- `undefined` / `'reps'` — обычные повторы (back-compat со старыми планами и
  сохранёнными сессиями).

Хелперы в `src/lib/domain/workoutDefaults.ts` (реэкспорт из `workout.ts`):

- `isTimedMeasure(ex)` — `seconds` или `minutes`;
- `timingMeasureFor(bodyPart)` — какая единица, если включить время:
  кардио → `minutes`, всё остальное → `seconds`;
- `formatExercisePrescription(ex, { seconds, minutes })` — `3 × 10`,
  `3 × 45 сек`, `3 × 20 мин`, ладдер остаётся `5 · 5→1`.

## Билдер

В шите действий упражнения — переключатель «Считать по времени» /
«Считать по повторам» (`WorkoutExerciseRow.svelte`, RN — `builder/[planId].tsx`).
Степпер подписывается той единицей, которая выбрана (Повторы / Секунды / Минуты).

- Единицу не угадываем по названию («Планка со скручиванием» неоднозначна) —
  решает `measure`, а дефолтную единицу даёт только `body_part`.
- При включении времени подставляется правдоподобное значение: минуты — 20,
  секунды — 30 (если было ≤ 20 повторов), иначе оставляем число как есть.
  При возврате к повторам значение > 30 превращается в 10.
- Ладдер и `repsScheme` для времени не имеют смысла: ладдер скрыт, схема
  очищается при переключении.

## Live

Тайминг-подход (`LiveSetPanel.svelte`, RN — `LiveSetRow.tsx`):

- колонки веса нет вообще;
- заголовок колонки — «Секунды» / «Минуты», поле ввода — та же длительность;
- у незавершённого подхода есть кнопка-секундомер: старт → тикает `m:ss` →
  стоп записывает длительность и сразу закрывает подход (дальше идёт отдых);
- таймер привязан к упражнению: смена упражнения сбрасывает показания;
- запись при стопе: секунды — округление до секунды, минуты — до минуты,
  минимум 1 (иначе «0 мин» выглядит как ошибка).

## Что время НЕ должно ломать

- Тоннаж (`sessionVolumeKg`) и личные рекорды (`recordsFromFinishedSession`)
  пропускают `seconds` / `minutes`: «лучшие 45 повторов» из планки — ложь.
- Кардио по-прежнему `skipLiftChecks`: вес не спрашиваем.
- Итоги/история показывают длительность с единицей (`45 сек`, `20 мин`), а не
  `вес × повторы`.

## Тесты

`tests/e2e/hold-timer.spec.ts`:

- билдер: планка → «Считать по времени» → чип «Секунды», `measure: 'seconds'`
  сохраняется; кардио → «Минуты» и дефолтные 20;
- превью плана `2 × 45 сек` / `2 × 20 мин`;
- live: заголовок колонки, отсутствие поля веса, секундомер пишет значение и
  закрывает подход;
- итоги: `1 мин` после минутного подхода.
