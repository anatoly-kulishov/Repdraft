# Упражнения по времени (секунды / минуты)

Планка, вис, стенка — это время, а не повторы. Беговая дорожка, велотренажёр,
эллипс — тоже время, только в минутах. Реп-поле (`reps`) в таких упражнениях
хранит длительность, а не количество повторов — отдельного поля нет намеренно:
так не пришлось трогать 700+ мест, где читается `reps`.

## Данные

```ts
type ExerciseMeasure = 'reps' | 'seconds' | 'minutes';
```

- `WorkoutExercise.measure?: ExerciseMeasure` — в плане (билдер);
- `SessionExercise.measure?: ExerciseMeasure` — копируется в сессию при
  `startSessionFromPlan` / `replaceSessionPlan` / `syncSessionPrescriptionFromPlan`
  (`src/lib/domain/sessionLifecycle.ts`), поэтому live знает про время и после
  подмены плана на ходу. Явный `'reps'` тоже копируется — иначе каталожный
  дефолт вернул бы планке секунды против воли атлета;
- `undefined` — строка сохранена до появления `measure` (или это обычный лифт):
  единицу добираем из каталога, см. ниже.

Хелперы в `src/lib/domain/workoutDefaults.ts` (реэкспорт из `workout.ts`):

- `isTimedMeasure(ex)` — `seconds` или `minutes`;
- `defaultMeasureFor(hint)` — единица «по каталогу»: планка/изометрия →
  `seconds`, устойчивое кардио (дорожка, велотренажёр, эллипс, скакалка,
  ходьба, гребля) → `minutes`, остальное (включая берпи и прыжки) → `reps`;
- `measureOf(ex, hint)` — сохранённый `measure`, иначе каталожный дефолт.
  Именно её читают билдер, live, превью, итоги и история, поэтому старый план
  с планкой открывается как «45 сек», а не «45 повторов»;
- `timingMeasureFor(bodyPart)` — какая единица, если атлет сам включает время:
  кардио → `minutes`, всё остальное → `seconds`;
- `durationSeedFor(measure, reps)` / `repsFromDuration(measure, value)` — пара
  для переключателя (30 сек / 20 мин ↔ правдоподобные повторы);
- `planWithResolvedMeasures(plan, hintFor)` — материализует дефолт в план перед
  стартом сессии, чтобы тоннаж и рекорды видели `measure`;
- `formatExercisePrescription(ex, { seconds, minutes })` — `3 × 10`,
  `3 × 45 сек`, `3 × 20 мин`, ладдер остаётся `5 · 5→1`.

## Билдер

В шите действий упражнения — переключатель «Считать по времени» /
«Считать по повторам» (`WorkoutExerciseRow.svelte`, RN — `builder/[planId].tsx`).
Степпер подписывается той единицей, которая выбрана (Повторы / Секунды / Минуты).

- Дефолт даёт каталог, а не название из головы: `defaultMeasureFor` смотрит на
  `name_ru` / `name` и `body_part`. Планка и изометрия — секунды, дорожка и
  другой «ровный» кардио-снаряд — минуты, прыжковое кардио — повторы.
- Добавление из каталога сразу пишет `measure` и правдоподобное значение:
  планка → 30 сек, дорожка → 20 мин. Хинт (`name_ru`, `body_part`) передают все
  точки входа: каталог, карточка, страница упражнения, частые, RN-пикеры.
- «Считать по повторам» ставит `measure: 'reps'` явно — каталожный дефолт его
  не перебивает. Значение пересчитывается: 45 сек → 9 повторов, 20 мин → 10.
- При включении времени подставляется 30 сек (было ≤ 20 повторов) или 20 мин;
  если повторов больше 20 — оставляем число (60 повторов → 60 сек).
- Ладдер и `repsScheme` для времени не имеют смысла: ладдер скрыт, схема
  очищается при переключении.
- В RN секунды шагаются по 5 (`Stepper`), чтобы 30 → 45 не требовало 15 тапов.

## Live

Тайминг-подход (`LiveSetPanel.svelte`, RN — `LiveSetRow.tsx`):

- колонки веса нет вообще;
- заголовок колонки — «Секунды» / «Минуты», поле ввода — та же длительность;
- у незавершённого подхода есть кнопка-секундомер: старт → тикает `m:ss` →
  стоп записывает длительность и сразу закрывает подход (дальше идёт отдых);
- таймер привязан к упражнению: смена упражнения сбрасывает показания;
- запись при стопе: секунды — округление до секунды, минуты — до минуты,
  минимум 1 (иначе «0 мин» выглядит как ошибка).

Колонки «Статус / Не отмечен» больше нет: даже прыжковое кардио (берпи, джампы)
считается повторами, а поле можно просто не заполнять — галочка «готово»
работает как раньше.

## Что время НЕ должно ломать

- Тоннаж (`sessionVolumeKg`) и личные рекорды (`recordsFromFinishedSession`)
  пропускают `seconds` / `minutes`: «лучшие 45 повторов» из планки — ложь.
  Поэтому `planWithResolvedMeasures` вызывается на старте сессии (веб —
  `stores/live.ts`, RN — `live/[planId].tsx`, `useCycleScreen`, программы).
- Кардио по-прежнему `skipLiftChecks`: вес не спрашиваем.
- Итоги/история показывают длительность с единицей (`45 сек`, `20 мин`), а не
  `вес × повторы`.

## Тесты

`tests/e2e/hold-timer.spec.ts`:

- билдер: планка без `measure` сразу открывается чипом «Секунды»;
  «Считать по повторам» сохраняет `measure: 'reps'` и 9 повторов из 45 сек;
- дорожка без `measure` открывается «Минутами», переключение в повторы тоже
  сохраняет явный `'reps'`;
- превью плана `2 × 45 сек` / `2 × 20 мин`;
- live: заголовок колонки, отсутствие поля веса, секундомер пишет значение и
  закрывает подход; явный `'reps'` у планки оставляет «Повторы» без таймера;
- итоги: `1 мин` после минутного подхода.

`npm run check:domain` дополнительно гоняет `runWorkoutDefaultsSelfCheck()` и
проверяет дефолт на реальном каталоге (планки → секунды, дорожка и эллипс →
минуты, берпи и джампы → повторы).
