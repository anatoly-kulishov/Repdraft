## Width policy decision

Status: **decided (hybrid + account center)**

For v0.17.8:

- Keep **left-hug** next to sidebar for most app pages.
- **Account (≥1024):** catalog-width column **centered** in main; restore shell horizontal padding (no flush-to-sidebar).
- **Account grid:** short panels paired (greeting / interface / rest / help); checklist + export / danger / account span full width.
- **Tablet 768–1023:** mobile chrome; same 2-col pairing.
- **Sheets on desktop:** keep bottom sheets (P2 polish only if audit reopens).
