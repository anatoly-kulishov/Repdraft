# Рекламные материалы Repdraft

`npm run ads` снимает русскую тёмную версию веб-приложения с локальными демо-данными. Результат находится в `marketing/ads/<YYYY-MM-DD>/`. Каталог исключён из git.

| Папка | Размер | Материалы |
|---|---|---|
| `clean/` | 1080×2400 PNG | 12 экранов без рекламного оформления |
| `posts/` | 1080×1350 JPEG | 4 поста для ленты Telegram и VK |
| `stories/` | 1080×1920 JPEG | 3 сторис с полями по 274 px сверху и снизу |
| `landing/` | 1600×1000 JPEG | Главный баннер и блок про секундомер |

Тексты четырёх постов лежат в `README.md` рядом с кадрами. Они берутся из тех же записей, что заголовки и имена JPEG.

## Запуск

```bash
npm run ads
ADS_SKIP_BUILD=1 npm run ads
ADS_ONLY=clean npm run ads
ADS_ONLY=cards npm run ads
```

Полный прогон вызывает `scripts/e2e-server.mjs`, собирает гостевой production-бандл и поднимает adapter-node на порту 4310. Для Supabase, ИИ и оплаты используются пустые ключи. Быстрый прогон требует свежей сборки с теми же настройками. Режим `clean` обновляет только PNG. Режим `cards` читает готовые PNG и обновляет девять JPEG и тексты без сервера и сборки.

По умолчанию дата набора и часов приложения зафиксирована на 26 ноября 2026 года, часовой пояс Europe/Moscow. Для другого выпуска задайте `ADS_STAMP=YYYY-MM-DD`. `ADS_OUT` меняет папку вывода, `ADS_PORT` меняет порт, `ADS_BASE` указывает на уже запущенный локальный гостевой сервер.

## Как устроена съёмка

- В `scripts/capture-ads.mjs` фикстуры `PLANS`, `SESSIONS` и `CYCLE` попадают в localStorage нового браузерного контекста. На главной закреплён силовой план. ИИ получает локальный пример ответа через мок GET и POST `/api/ai/plan`.
- Экраны снимаются в Chromium с viewport 360×800 при DPR 3. Статичное изображение техники берётся из каталога. Для планки запускается настоящий секундомер, затем часы переводятся на 32 секунды. Движение интерфейса отключено через настройку уменьшенной анимации и параметры снимка.
- Плавающий таббар скрывается на `/cycle` и `/progress`. Билдер снимается последним, поскольку открытие редактора добавляет черновик в док. Остальные экраны сохраняют навигацию приложения.
- Для карточек `DETAILS` задаёт прямоугольники в координатах исходного viewport 360×800. `sharp` берёт соответствующие пиксели из PNG. По одному фрагменту на макет достаточно, чтобы прочитать строку подхода или легенду графика в ленте.
- Шаблон использует CSS, сгенерированный из `src/lib/design/tokens.ts`, локальные файлы Inter и иконку Repdraft из `static/`. JPEG экспортируются с качеством 90.

## Проверка после правок

Запустите `node --check scripts/capture-ads.mjs` и `npm run check`. Откройте кадры целиком, затем проверьте посты при ширине 350-400 px. После изменений в интерфейсе проверьте границы фрагментов в `DETAILS`, совпадение цифр с фикстурами и расположение всех элементов сторис между y=250 и y=1670.
