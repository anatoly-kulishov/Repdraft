# Сценарии QA

Открыть: [/auth](/auth) → **Сценарии** или [/scenarios](/scenarios).

Проверяй на **iPhone (Safari)** и **Android (Chrome)**. В каждом блоке: сначала **успех**, затем **ошибки и отмены**.

---

## P0. Тренировка целиком

### 1. От главной до истории (успех)

**Старт:** есть план, нет активной тренировки.

1. Открыть главную `/`.
2. Тап по блоку с планом или **Старт** → превью `/workouts/[id]`.
3. **Начать** → активная тренировка `/live/[id]`.
4. Записать вес и повторы → **Готово** → **Далее**.
5. **Завершить** → подтвердить в панели снизу.
6. На экране итога нажать **Готово**.
7. Открыть запись во вкладке **История**.

**Ожидаем:** подходы сохранены, время и объём на итоге, запись в истории.

### 2. Продолжить после закрытия (успех)

1. Начать тренировку, ввести один подход.
2. Закрыть вкладку или приложение.
3. Снова открыть главную → **Продолжить тренировку**.
4. Дозаписать подходы и завершить.

**Ожидаем:** данные на месте, тот же план.

### 3. Ошибки и отмены в тренировке

| Ситуация | Действие | Ожидаем |
|----------|----------|---------|
| Передумал завершать | **Завершить** → **Ещё нет** | Остаёмся в тренировке |
| Сброс без сохранения | **Сбросить** → подтвердить | Возврат к списку, записи в истории нет |
| Пустой план | **Начать** с планом без упражнений | Сообщение, что упражнений нет; переход в редактор |
| Уже идёт другая тренировка | **Начать** другой план | Предложение сбросить старую или отказаться |
| Удалили план, сессия осталась | Открыть активную запись | Подсказка: план удалён, можно продолжить или сбросить |
| Без интернета | Записать подход | Сохранение на телефоне, без полноэкранной загрузки |
| Неверные повторы | Пустое поле или >500 | Сообщение об ошибке, подход не закрывается |
| Пропуск упражнения | **Пропустить** → подтвердить | Упражнение пропущено, переход дальше |

## P0. Запись подхода

### 4. Обычный подход (успех)

1. Выбрать упражнение.
2. Ввести вес и повторы (или **прошлый раз**).
3. **Готово** → отдых (если задан) → **Далее**.

**Ожидаем:** галочка на подходе, автосохранение.

### 5. На все подходы сразу (успех)

**Старт:** 2+ незавершённых подхода у упражнения.

1. Ввести вес → тап **Вес** (подпись «На все»).
2. Ввести повторы → тап **Повторы** («На все»).

**Ожидаем:** значения скопированы на все открытые подходы.

### 6. Снять отметку с подхода

1. После **Готово** → **Изменить подход** (или снять отметки со всех).
2. Исправить вес/повторы → снова **Готово**.

**Ожидаем:** подход снова редактируется, история не ломается.

## P1. Планы тренировок

### 7. Создать план (успех)

1. **Тренировки** → **+** → редактор.
2. Название → **Добавить** → каталог → **+** на упражнении.
3. Подходы и повторы → **Сохранить**.

**Ожидаем:** план в списке, можно начать с превью.

### 8. Ошибки в редакторе

| Ситуация | Действие | Ожидаем |
|----------|----------|---------|
| Пустой список | **Сохранить** без упражнений | Нельзя или подсказка добавить упражнения |
| Очистить черновик | **Очистить** → подтвердить | Список пуст, можно отменить через сообщение |
| Удалить строку | Свайп / удалить | **Отменить** в сообщении → строка возвращается |
| Сохранение не прошло | (сбой хранилища) | «Не удалось сохранить», данные на экране |
| Клавиатура закрылась | Фокус в подходы/повторы → закрыть клавиатуру | **Добавить** и **Сохранить** снова у нижнего края (без чёрной дыры под панелью) |

### 9. Список планов

**Успех:** swipe вправо → **Следующая**; swipe влево → **Удалить** → **Отменить** в сообщении.

**Ошибки:**

| Ситуация | Ожидаем |
|----------|---------|
| Удалили план | **Отменить** в сообщении → план снова в списке |
| Один план | Режима перестановки нет или не мешает |

## P1. Каталог упражнений

### 10. Поиск (успех и пусто)

**Успех:** **Упражнения** → поиск → карточка → детали.

**Пустой результат:** запрос без совпадений → «Ничего не найдено», кнопка сброса фильтра.

**Назад свайпом (iPhone):** зона каталога или детали → свайп назад на **Упражнения** / **Главная** / **Тренировки**. Без лишнего мерцания шапки и tabbar.

### 11. Детали упражнения

**Успех:** закладка, **Добавить в план**, табы техника / история / рекорд.

**Ошибки:**

| Ситуация | Ожидаем |
|----------|---------|
| Уже в черновике | «Уже в плане», без дубля |
| Сняли закладку | **Отменить** → закладка на месте |
| Неверный рекорд | Сообщение о диапазоне веса/повторов |

## P1. История и итог

### 12. История (успех)

1. **Тренировки** → **История** → запись.
2. Режим правки → изменить вес/повтор → сохранить.
3. **Отправить в редактор** → черновик из записи.

**Ожидаем:** правки в истории, черновик открывается.

### 12a. Фильтры истории

**Старт:** несколько записей в разные дни.

1. Поиск по названию плана → список сужается.
2. Чип **Сегодня** → только сегодняшние; повторный тап снимает фильтр.
3. Чип **Период** → панель календаря: первый тап = начало, второй = конец → фильтр применяется, панель закрывается.
4. Иконка **X** в ряду фильтров → сброс поиска и периода.
5. Пустой результат фильтра → «Ничего не найдено», кнопка **Сброс**.

**Ожидаем:** чипы и X в одну строку на телефоне; длинный период обрезается с многоточием; в календаре дни диапазона подсвечены.

### 12b. История упражнения в live

1. В активной тренировке на карточке упражнения открыть иконку истории.
2. В панели снизу посмотреть прошлые подходы.
3. Закрыть панель, продолжить запись.

**Ожидаем:** панель не сбивает текущий подход.

### 13. Удаление истории

| Ситуация | Действие | Ожидаем |
|----------|----------|---------|
| Одна запись | Свайп → удалить | **Отменить** → запись вернулась |
| Вся история | **Очистить историю** → подтвердить | Пустой список; **Отменить** → всё вернулось |
| Не удалилось | Повторить при сбое | Сообщение об ошибке, данные на месте |

### 14. Экран итога (гость)

**Успех:** после завершения → метрики, **Готово**.

**Подсказка гостю:** «Сохранить в аккаунте?» → можно **Позже** или перейти в профиль.

## P1. Профиль, вход, копия

### 15. Гость (успех)

1. Без входа: план, тренировка, история только на телефоне.
2. В профиле: язык, тема, резервная копия доступны.

### 16. Вход и регистрация

**Успех:** email + пароль → вход → данные с телефона не пропали.

**Ошибки:**

| Ситуация | Ожидаем |
|----------|---------|
| Неверный пароль | «Неверный email или пароль» |
| Email не подтверждён | Просьба подтвердить почту |
| Пароли не совпадают (регистрация) | До отправки на сервер |
| Слабый пароль (короткий / частый) | Подсказки политики, регистрация не уходит |
| Email уже занят | Предложение войти |
| Слишком много попыток | Подождать минуту |
| Устаревшая ссылка из письма | Запросить новую |
| Вход недоступен (нет облака) | Панель «Вход пока недоступен», локально всё работает |
| Выход | Данные на устройстве на месте, сообщение «Вы вышли» |
| Выход на всех устройствах | Подтверждение в панели снизу → сессии везде сброшены |
### 17. Резервная копия

**Успех:** **Скачать копию** → файл; **Восстановить** → панель → данные объединены с текущими.

**Ошибки:**

| Ситуация | Ожидаем |
|----------|---------|
| Нечего сохранять | «Пока нечего сохранять» |
| Не тот файл | «Это не файл резервной копии Repdraft» |
| Битый файл | «Не удалось прочитать файл» |
| Старая версия файла | «Версия файла не поддерживается» |
| Отмена в панели | Данные не меняются |
| Облако недоступно после восстановления | Локально ок, предупреждение об отложенной синхронизации |

### 18. Удаление аккаунта

1. **Опасная зона** → ввести **УДАЛИТЬ** → подтвердить.

**Ошибки:** неверное слово → кнопка неактивна; нет сессии → войти снова; сервер недоступен → сообщение, аккаунт на месте.

## P1. Пустые экраны

| Экран | Условие | Ожидаем |
|-------|---------|---------|
| Главная | Нет планов | Создать тренировку / демо |
| Тренировки | Нет планов | Кнопка **+**, текст-подсказка |
| Редактор | Нет упражнений | **Добавить упражнение** |
| Закладки | Пусто | Подсказка про закладку на упражнении |
| Рекорды | Пусто | Подсказка открыть упражнение |
| Статьи | Поиск без результатов | Пустое состояние + сброс |
| История | Фильтр без совпадений | «Ничего не найдено» + **Сброс** |
| 404 | Несуществующий URL | «Страница не найдена», ссылки домой |

## Быстрый прогон после правок

1. Сообщение с **Отменить** - план, закладка, история, черновик.
2. Панель снизу - завершение, сброс, восстановление копии, очистка истории, период в истории, выход везде.
3. Зоны нажатия от 48 px - **Готово**, назад, tabbar, **X** фильтра истории.
4. Без сети в активной тренировке - запись и reload.
5. Свайп назад на корневые вкладки - без мерцания chrome (шапка / tabbar).
6. Редактор: закрыть клавиатуру после полей подхода - sticky **Добавить** / **Сохранить** у низа.
7. История: **Сегодня** + **Период** + **X** в одну строку; диапазон двумя тапами в календаре.
