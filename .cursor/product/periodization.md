# Волновая периодизация (cycle)

Экран `/cycle` + карточка в `/workouts`: один мезоцикл на 8–12 недель, который
модулирует объём и интенсивность сохранённых планов. Идея — классическая схема
волновой периодизации: объём и интенсивность идут в противофазе, блоками по три
недели. Веб (SvelteKit) и RN используют один домен (`src/lib/domain/cycle.ts`) и
один ключ `repdraft:cycle`, но у каждого клиента своё локальное хранилище.

## Модель волны

Порядок внутри блока: **интенсивность → объём → пик объёма**.

| Неделя блока | Тип | Объём | Интенсивность |
|---|---|---|---|
| 1 | `intensity` | 80 % | 110 % |
| 2 | `volume` | 105 % | 95 % |
| 3 | `volumePeak` | 118 % | 85 % |

Недели цикла считаются от `startDate` (понедельник недели создания), ровно по
7 дней. После последней недели цикл «завершён», но остаётся в хранилище, пока
его не сбросят.

## Как волна ложится на план

`cycleWeekVariant(plan, week, cycle)` — чистый вариант плана на неделю:

- `plan.id` сохраняется (live/resume находят план), в имени префикс «нед. N»;
- `sets` / `reps` / `restSec` сдвигаются на дельты цели (`strength`, `muscle`,
  `cut`, `endurance`, `habit`) и клэмпятся через `inputLimits`;
- `groupId` / `altGroupId` и порядок упражнений не трогаются;
- лесенка `repsScheme` снимается, если изменилось число сетов.

Старт недели идёт через `live.startFromPlan(variant, { lockPrescription: true })`,
как «Сегодня» в `planTune`: сохранённый план не перезаписывается. Поэтому в
истории видно «нед. 3 · Грудь + трицепс», а `planId` остаётся исходным — по нему
и считается прогресс цикла.

## Данные

- Ключ `repdraft:cycle`, один активный цикл, **только локально** (как
  `athleteProfile`). Облачной синхронизации нет: нет таблицы и RLS.
- Веб: стор `src/lib/stores/cycle.ts` над `localStorage`; RN: `mobile/src/state/cycle.ts`
  над AsyncStorage (`kv`).
- Прогресс не хранится: он выводится из истории (завершённые сессии,
  `planId ∈ cycle.planIds`, дата внутри недели).
- Сброс цикла удаляет только запись цикла; планы и тренировки остаются.

## Клиенты

- **Web**: `src/routes/cycle/+page.svelte` (настройка, график, недели), карточка
  в `/workouts`, бейдж в шапке главной, чип в превью плана.
- **RN**: `mobile/app/cycle.tsx` + `mobile/src/cycle/useCycleScreen.ts`, SVG-график
  `mobile/src/cycle/CycleWaveChart.tsx` (react-native-svg, `chartVolume` из
  палитры), карточка в табе «Тренировки», бейдж в `PlanHeroCard`, чип в
  `mobile/app/plan/[id].tsx`. Неделя стартует так же — вариант + `lockPrescription`.

## Проверки

`npm run check:domain` гоняет `runCycleSelfCheck` (порядок волн, проценты,
клэмпы, сохранение групп/дублей упражнений, границы недель, фильтр сессий,
нормализация хранилища). Перед «готово» — `npm run check:parity` (токены,
версии, домен, веб + RN тайпчек).
